# Data-Science-coursera-project
# Analyzing Historical Stock and Revenue Data

## Project Overview
This project analyzes historical stock prices and quarterly revenue data for **Tesla (TSLA)** and **GameStop (GME)** using Python. The objective is to collect financial data, perform basic data cleaning, and visualize stock price trends to understand how stock performance compares with company revenue over time.

## Objectives
- Extract historical stock price data using the `yfinance` library.
- Collect company revenue data through web scraping with `pandas` and `BeautifulSoup`-related HTML parsing tools.
- Clean and process financial data using Pandas.
- Create stock price graphs using Matplotlib.
- Compare historical stock price movements and revenue trends for Tesla and GameStop.

## Tools and Technologies
- **Python**
- **Pandas** — data manipulation and analysis
- **yfinance** — historical stock data extraction
- **Web Scraping** — retrieving revenue tables from web pages
- **BeautifulSoup / HTML parsers** — HTML processing support
- **Matplotlib** — data visualization
- **Jupyter Notebook / Google Colab** — development environment

## Project Tasks
1. Extract Tesla historical stock data.
2. Extract Tesla revenue data using web scraping.
3. Extract GameStop historical stock data.
4. Extract GameStop revenue data using web scraping.
5. Visualize Tesla stock price trends.
6. Visualize GameStop stock price trends.

## Key Outcomes
- Practiced retrieving financial data from online sources.
- Learned to clean and manipulate tabular data using Pandas.
- Developed time-series visualizations for historical stock prices.
- Explored the relationship between company revenue and stock market performance.

## How to Run
1. Clone or download this repository.
2. Open the Jupyter Notebook in Google Colab or Jupyter Notebook.
3. Install the required libraries if necessary:

   ```bash
   pip install yfinance pandas matplotlib lxml html5lib
   ```

4. Run the notebook cells in order.
5. Review the extracted datasets and generated visualizations.
